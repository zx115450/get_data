## 输入格式

第一行包含一个整数 $t$（$1 \leq t \leq 100$），表示测试数据组数。

对于每组测试数据：

- 第一行包含一个整数 $n$（$1 \leq n \leq 10^4$），表示花的数量。
- 第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n$（$0 \leq a_i \leq 10^9$），表示每朵花的新鲜值。
- 第三行包含一个整数 $m$（$1 \leq m \leq 10^6$），表示询问次数。
- 接下来 $m$ 行，每行包含一个整数 $k$（$0 \leq k \leq 2 \times 10^9$），表示每次询问的阈值。

## 数据范围

- $1 \leq t \leq 100$
- $1 \leq n \leq 10^4$
- $0 \leq a_i \leq 10^9$
- $1 \leq m \leq 10^6$
- $0 \leq k \leq 2 \times 10^9$
- 所有测试数据的 $n$ 之和不超过 $10^4$。
