# 2026-08-19 项目优化纪要

本文汇总当日对 `get_data` Agent 数据生成流水线的优化：背景问题、改动内容、涉及文件与验证方式。优化原则是 **通用、可拦截、少绑单题语义**——用提示词降低误写概率，用 `write_gen` / 自检硬门禁在编译前或失败日志里打回。

---

## 1. 背景

当日多轮同题任务（玩具木棍 / 欧拉路径类图题）暴露出三类可复现故障，换更大模型后更容易复发：

| 现象 | 典型报错 / 产物 | 表面误诊 |
| --- | --- | --- |
| Validator 多读一轮 | `Unexpected end of file - token expected`（行号常为记录数 +1） | 以为 gen 少打字段 |
| 大档 random 状态爆炸 | `std TIMEOUT`（fast 过、full 挂） | 只调时限 / 略收 `n` |
| random 空白测例 | `out/*.in` 大量 0 字节，自检仍绿灯 | 以为打包或落盘坏了 |

根因分别是：testlib `eof()` 与尾随换行、大档无有限域复用、constraints 只 `opt` 未赋值（如 `word_len` 停在 0）。系统原先多靠长 prompt 软约束，缺少可执行的静态检查。

---

## 2. 优化总览

```text
Prompts（教对写法）
    → write_gen 静态门禁（错写法当场 ERROR）
    → self_check 定点提示（失败日志指向根因）
```

当日完成三块，均要求 **题型无关表述**（有效状态 / 有限域 / constraints 赋值），不写死单题字段名。

| 编号 | 主题 | 手段 |
| --- | --- | --- |
| A | Validator 读至 EOF | Prompts + Fixer 误诊纠正 + 自检提示 |
| B | 大档有效状态 ≤ K | Prompts + `write_gen` 静态门禁 |
| C | random 对 constraints 显式赋值 | Prompts + `write_gen` 静态门禁 |

未改：自检「`strip` 后空输入一律落空文件」策略（C 从生成侧堵住漏赋值；套件级「random 禁止空 in」留作后续）。

---

## 3. 优化 A：Validator `eof()` / 尾随换行

### 3.1 问题

无规模头、读到 EOF 的题，Agent 常写：

```cpp
while (!inf.eof()) {
    inf.readToken(...);
}
```

`eof()` 不跳空白；末行 `\n` 仍使 `!eof()` 为真，再读 token 即失败。标程 `while (cin >>)` 按「有无下一 token」结束，语义不一致。

### 3.2 改动

- Planner 第 6 节：强制 `while (!inf.seekEof())`；拒收 `while (!inf.eof())`
- `_VALIDATOR_GATE`：硬门禁 + EOF 骨架示例（含 `skipBlanks` + `readEof`）
- Coder / Rewrite / Gen Fixer：行号 = 末行 +1 或多 type 同挂 → **优先改 validator**，勿改 gen 删换行
- `BASE_VAL_RULES`、`write_validate` schema 同步
- Gen Fixer prompt 挂上 `_VALIDATOR_GATE`
- 自检：有输出仍报 `Unexpected end of file` 时追加 seekEof 定点提示

### 3.3 正确写法（摘要）

```cpp
while (!inf.seekEof()) {
    // readToken / read*
}
inf.skipBlanks();
inf.readEof();
```

## 4. 优化 B：大档有效状态有限域复用

### 4.1 问题

Plan / edge 写了「大档 ≤ K」，但 random 规模循环内仍：

- 每次 `rnd.next("[a-z]{…}")` 新 token，或
- 每次 `rnd.next(…, 1e9)` 新宽域值

导致唯一状态 ≈ 规模，标程 Trie / 无压缩并查集等易 `std TIMEOUT`。fast 只压小档 index，满测才暴露。

### 4.2 改动

**Prompts**

- 新增 `_FINITE_DOMAIN_GATE`（Coder / Rewrite / Gen Fixer）
- Planner：大档须写「先建 `pool[K]`、循环内只采样」；拒收只写「≤ K」无 pool 句
- `TYPE_GRAPH` / `TYPE_ARRAY` / `TYPE_STRING`：用「有效状态 / 数值种类 / token」表述
- Fixer：大档 `std TIMEOUT` 先查缺有限域

**静态门禁**（`agent/tools/write.py`）

- `_check_gen_random_unbounded_states`
- 同时满足才拦：random 分支 + 大档规模痕迹 + `for` 内无界 token/宽整数采样 + 无 pool 痕迹（`pool` / `palette` / `domain` / `vector<string>` 等）

**自检**

- `type=random` 且 `(index/3)%3==2` 的 `std TIMEOUT` 追加「疑似大档缺有限域」提示

### 4.3 正例（摘要）

```cpp
vector<string> pool;
// 先填 ≤K 个互异状态
for (int i = 0; i < n; i++) {
    auto x = pool[rnd.next(0, (int)pool.size() - 1)];
    // 输出 x
}
```

## 5. 优化 C：random 对 constraints 显式赋值

### 5.1 问题

`opt<int>("word_len", 0)` 只消费 unused key，**默认 0 不是构造赋值**。random 只设规模、漏设长度/种类时：

1. 颜色池推进空串，stdout 变成多行 `" \n"`
2. 自检 `if (!raw_in.strip())` 落成 0 字节 `.in`
3. 无规模头题 validator / std 对空文件仍通过 → 自检绿灯

边例（显式设了长度）有内容，random 槽位大面积空文件，表现为「最新生成全是空 in」。

### 5.2 改动（仅生成侧，按需求）

**Prompts**

- 新增 `_CONSTRAINT_ASSIGN_GATE`
- Planner 第 4/8 节与拒收话术：random 须对全部 constraints 显式 `name = ...`
- opt 样板注释强调禁止只 opt 沿用 0
- `BASE_GEN_RULES` 同步

**静态门禁**

- `_check_gen_random_constraint_assigns`
- 读取 `range.json` 的 constraints 键；在 `type == "random"` 分支内每个名至少一次 `name =`（排除 `==`）
- 对当日漏赋 `word_len` 的 gen：编译前直接 BLOCK

未做：自检侧「random 禁止空 in」——若需可另开任务。

## 7. 验证

已跑：

```bash
python -m pytest tests/test_tools_validate.py -q
```

手工冒烟（概念）：

- 坏样：random 循环内 `rnd.next("[a-z]…")` 且无 pool → `write_gen` ERROR
- 坏样：random 有 `n =` 无 `word_len =`（constraints 含二者）→ ERROR
- 好样：先建 `pool` 再采样；random 内对各 constraints 赋值 → 通过门禁

---

## 8. 设计取舍

| 取舍 | 说明 |
| --- | --- |
| Prompt + 门禁双轨 | 大模型易表面合规；门禁不依赖自觉 |
| 门禁偏保守 | 大档痕迹 + 无 pool 才拦 token/宽整数，降低小档误杀 |
| constraints 赋值只要求 random 内至少一次 | 误报少；未强制每个 `bB` 档块都写一遍 |
| 不写单题特色 | 用「有效状态 / token / 宽值域 / constraints 名」 |

---

## 9. 后续可选

1. **自检**：`type=random` 且 `in_chars==0`（或 strip 后空）→ FAIL；空输入仅允许名单内 min/m0 类 edge
2. **赋值门禁加强**：存在 `bB==0/1/2` 时，要求每个档块都对关键轴赋值
3. **Range 审核**：有 GUI 候选且合理时，限制大幅改写 constraints / edge 语义，减少方案漂移

---

## 10. 一句话结论

当日把三类高频失败从「靠模型记住长规则」推进到 **可教 + 可拦**：EOF 用 `seekEof`、大档用有限域 pool、random 对每个 constraint 显式赋值；编译前静态门禁与定点自检提示共同降低换模型后的回归率。
